HOW TO PREVIEW
1. Extract the ZIP file.
2. Double-click index.html to open it in a browser.
3. Internet is only needed for the optional Google Fonts; the site layout itself is local.

HOW TO PUBLISH FOR FREE (WITHOUT BUYING A DOMAIN YET)
1. Create/sign in to a GitHub account at https://github.com/
2. Create a new public repository named: razvi-marriage-bureau
3. Upload index.html and style.css to the repository root.
4. Open repository Settings → Pages.
5. Under Build and deployment, choose Deploy from a branch.
6. Choose the main branch and /(root), then Save.
7. GitHub will provide a free address ending in github.io. Publishing can take a few minutes.

LATER, WHEN YOU BUY razvimarriagebureau.com
You can connect the domain in GitHub Pages settings by following GitHub's current custom-domain instructions. Do not buy hosting unless you decide you need it.
